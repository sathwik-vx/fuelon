# FuelOn – Never Get Stranded Again.

Emergency fuel & roadside assistance concept by **VISION X** (College Design Thinking Lab).

> **Academic Prototype – Demo Mode.** All services, availability, prices, providers and tracking information are simulated. No real fuel delivery, dispatch, payment or phone call takes place.

## Features
- Animated landing page
- Emergency fuel, roadside, and nearby petrol station flows (sample data)
- Automatic sample provider assignment
- Simulated AI voice confirmation call (browser SpeechSynthesis)
- Booking confirmation, cancellation, 5-step demo tracking
- Booking history, notifications, help centre, profile and vehicles
- Data saved in the browser (localStorage)

## Run locally
No installation needed. Open `index.html` in a modern browser (Chrome or Edge recommended for voice playback).

## Host on GitHub Pages
1. Add `index.html` and this `README.md` to a repository.
2. Go to **Settings → Pages**, choose the `main` branch and `/ (root)`, then save.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
